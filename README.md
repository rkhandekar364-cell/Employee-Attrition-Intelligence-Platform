# Employee Attrition Intelligence Platform

A full-stack HR analytics platform for analyzing employee workforce data, understanding employee attrition, performing exploratory data analysis, and generating business insights.

## 🚀 Features

- 📊 Executive HR Analytics Dashboard
- 👥 Employee workforce analysis
- 📈 Attrition rate analysis
- 🔍 Exploratory Data Analysis (EDA)
- 🤖 Employee attrition prediction
- 🧠 Machine Learning model evaluation
- 💡 Business insights and recommendations
- 📁 Employee dataset upload
- 🔐 PII masking for employee information

## 🛠️ Technology Stack

### Frontend
- React
- JavaScript
- HTML
- CSS
- Data visualization

### Backend
- Python
- FastAPI
- Machine Learning
- Data Analysis

### Database / Data
- Employee HR dataset
- CSV data processing

## 📌 Project Modules

1. **Executive Dashboard** – Workforce and attrition overview.
2. **Company Analytics** – Department and employee-level analytics.
3. **Attrition Predictor** – Predict employee attrition using ML.
4. **Exploratory EDA** – Explore patterns and relationships in HR data.
5. **Model Performance** – Evaluate machine-learning models.
6. **Business Insights** – Generate actionable HR recommendations.

## 📊 Dataset

The platform works with employee HR data containing information such as salary, department, job role, employee details, and attrition-related attributes.

## 🎯 Objective

The goal of this project is to help organizations understand employee turnover and use data-driven insights to identify potential attrition risks and improve employee retention.
